# Présentation de iPayMoney
iPayMoney vous donnne la possibilité de recevoir des paiements de partout dans le monde. Il constitue une solution dont l'intégration vous permet de recevoir les paiements effectués par Mobile Money (tous opérateurs confondus) et par Cartes de Crédit (locales et internationales).
Un compte marchand valide est obligatoire à l'utilisation de iPayMoney. L'inscription est gratuite si vous n'êtes pas encore inscrit.
iPayMoney met à votre disposition des SDKs ou Plugins dépendamment des technologies que vous utilisez afin de faciliter son intégration.
{% tabs %}
{% tab title="Avec une plateforme Native (Web ou Mobile )" %}
Un SDK Javascript et un SDK Android sont disponibles et intégrables au code de votre application.
{% endtab %}
{% tab title="Avec un CMS" %}
Vous disposez également d'un plugin WooCommerce intégrable à votre plateforme lorsque celle-ci est développée avec Wordress.
{% endtab %}

# Inscription et activation de compte iPayMoney
Bienvenue sur IPayMoney, une solution pour payer, transférer et encaisser en toute sécurité. Vous n’avez pas encore de compte ? Veillez suivre ces petites étapes simples pour vous inscrire :
Dans le navigateur de votre choix, saisissez le lien [i-pay.money](https://i-pay.money) puis faites Entrer.
Vous êtes automatiquement redirigés sur la page d’accueil de IPayMoney, comme présentée ci-dessous :
![](/files/-MlEfyQ0MXtrmhASQoZU)
Pour le nouvel utilisateur, veuillez cliquer sur S’inscrire, en haut de la page à droite, pour créer votre compte.
Après le clic, vous verrez une fenêtre demandant les informations de compte tels que votre adresse e-mail, votre nom, etc. comme indiqué dans sur l’image ci-dessous.
![](/files/-MlEgkyFarKGfjluzM2S)
Veuillez-y renseigner correctement votre adresse e-mail, votre nom, numéro de téléphone et mot de passe.
Lisez et acceptez les conditions d’utilisation de IPayMoney, puis validez la création de votre compte en cliquant sur Créer un compte.

# Soldes
### Reversement
Avec iPayMoney récupérez vos avoirs en tout temps et à tout instant. Vous pouvez à tout moment demander depuis votre tableau de bord le remboursement de vos avoirs. Cela s'appelle un reversement. Il se fait suivant les moyens de paiements qui suivent :
#### &#xD; Mobile money (Airtel money, ZamaniCash ou Moov money)
#### Compte bancaire (Ecobank)
1. **Configuration de la méthode de remboursement**
Vous pouvez dans le menu Paramètres de iPayMoney configurer vos préférences de remboursement. Trois (02) modes de reversement sont disponibles : le reversement par période et le reversement par palier.
* &#x20;**Reversement par période**
Le reversement par période vous permet de spécifier à quelle fréquence vous désirez procéder à la récupération de vos divers avoirs. Les fréquences de reversement sont les suivantes :
&#x20;              **Reversement journalier ;** &#x20;
&#x20;              **Reversement chaque 03 jours ;**
&#x20;              **Reversement hebdomadaire** (une fois par semaine si le solde du compte le permet);
&#x20;              **Reversement mensuel** (une fois par mois si le solde du compte le permet) ;
&#x20;              **Reversement annuel** (une fois par an si le solde du compte le permet).
&#x20; Ainsi, selon la fréquence choisie, tous vos fonds disponibles vous sont reversés via mobile money ou compte bancaire.
* **Reversement par palier**
Le reversement par palier vous permet de spécifier à partir de quel montant disponible sur votre compte, iPayMoney devra vous reverser vos avoirs. Ce montant est variable mais ne peut être inférieur à 50.000 Fcfa.
&#x20;&#x20;
&#x20;**2. Reversement sur compte**
**Reversement sur compte mobile money**
Vous pouvez demander le reversement de vos avoirs sur un compte mobile money. Il vous faudra, pour cela le renseigner sur l'interface de configuration des reversements. Un code sera ensuite envoyé par iPayMoney au numéro fourni afin de vérifier sa validité.
Aucun frais n'est appliqué aux reversements effectués via mobile money.
**Reversement sur compte bancaire**
Afin de demander un reversement de vos avoirs via compte bancaire, vous devez ajouter depuis votre tableau de bord, ledit compte. Selon que vous soyez une entreprise ou un particulier, les informations à renseigner sont différentes.
Les reversements via compte bancaire sont imputables de frais de transaction dont le montant s’élève à 7000 Fcfa par reversement, quel que soit le montant dudit reversement.

# Mode d'utilisation de iPayMoney
Dès votre inscription sur iPayMoney, des clés API sont mises à votre disposition dans le but d'intégrer l'agrégateur sur votre plateforme.
### Les clés de l'API iPayMoney <a href="#recuperation-des-cles-de-lapi-kkiapay" id="recuperation-des-cles-de-lapi-kkiapay"></a>
Dans le sous-menu **Clés API** du menu **Développeurs,** il est mis à  votre dispositon deux (02) clés API associées à votre compte iPayMoney : une clé publique et une clé secrète.
### L'intérêt des clés API
La clé publique iPayMoney comme son nom l'indique est destinée au public. Elle peut être intégrée dans vos code Javascript et Android. Elle doit être renseignée sur votre tableau WordPress dans la rubrique Paramètres de notre plugin WordPress.
Seuls un propriétaire de compte et iPayMoney connaissent la clé secrète de son compte. Elle est utilisée par le serveur pour valider les transactions sur votre compte iPayMoney.
Deux méthodes sont mises à disposition pour l'intégration de iPayMoney. On peut soit utiliser un Plugin ou un SDK conçus spécialement pour les intégrations.
Pour les sites conçus avec Wordpress, un Plugin spécifique est disponible pour l'intégration. Ce Plugin servira d'intermédiaire entre vos clients et vos offres de service. Dans le cas d'une application web ou d'une application mobile, vous devrez faire appel respectivement au SDK Javascript ou au SDK Android.

# Moyen de paiements
Pour éffectuer un paiement, le client choisi un moyen de paiement. À ce jour, les moyens de paiement disponibles sur iPayMoney sont les suivants:&#x20;
* Le mobile money (Airtel Money, ZamaniCash et Moov Money);
* Les cartes de crédit (Visa et Mastercard).
### Mobile money : Airtel Money, ZamaniCash et Moov Money <a href="#mobile-money-mtn-mobile-money-et-moov-money" id="mobile-money-mtn-mobile-money-et-moov-money"></a>
Pour faire un paiement à travers mobile money, il est obligatoire que le client dispose d'un compte Airtel Money ou ZamaniCash ou encore Moov Money actif et authentifié avec ses informations personnelles. Une fois les informations de compte mobile money renseignées sur iPayMoney, l'opérateur de téléphonie mobile enverra directement au client un message notifiant l'opération de débit sur son compte mobile money. Le compte sera debité si et seulement si le client dispose de la somme requise et approuve la ténue de l'opération. Ainsi, le compte iPayMoney du marchand est credité avec la somme équivalente et la transaction est alors réussie.
### Les cartes Visa et MasterCard <a href="#carte-de-credit-visa-mastercard" id="carte-de-credit-visa-mastercard"></a>
Pour faire un paiement ou achat en ligne sur iPayMoney avec votre carte Visa ou MasterCard, veuillez tout simplement remplir les informations sur votre compte et les informations de votre carte telles que :
* [ ] Votre nom et prénom ;
* [ ] Le numéro de la carte en question (16 chiffres) ;
* [ ] La date d’expiration de la carte (MM/AA) ;
* [ ] Le code de sécurité de la carte (03 chiffres).
Si le client dispose de la somme requise sur son compte bancaire, la banque auprès de laquelle il a souscrit sa carte débitera ledit compte et fera notifier l'opération au client à travers un SMS ou un mail. Le client sera automatiquement informé du succès de la transaction par iPayMoney. Le compte iPayMoney du marchand sera crédité par ladite somme. &#x20;
{% hint style="info" %}
La devise utilisée pour faire les paiements devra être le Franc CFA (FCFA).
{% endhint %}
# Frais liés aux opérations
Selon la nature de chaque opération, iPayMoney prélève des frais. Ces frais sont prélevés de la manière suivante :
### Frais à l'achat
* Au moment de l'encaissement de chaque paiement à travers mobile money, **3%** du montant de l'opération est prélévé.&#x20;
* Pour toutes les opérations éffectuées avec une carte Visa ou MasterCard, des frais à hauteur de &#x33;**%** du montant des achats sont prélévées.&#x20;
### Frais liés au reversement sur mobile money <a href="#frais-preleves-aupres-de-vos-clients" id="frais-preleves-aupres-de-vos-clients"></a>
Il y a deux traitements différents en fonction des lieux.
* Pour une opération à l'intérieur du Niger :
Au moment du reversement de vos avoirs par iPayMoney aucun frais n'est prélévé.
* Pour une opération en dehors du Niger:
Au moment du reversement, des frais seront prélévés pour d'autres pays en fonction de leurs politiques de facturation des opérations.

# Retirer vos fonds
iPayMoney vous permet de récupérer vos avoirs sous deux méthodes :&#x20;
* mobile money (Airtel money, ZamaniCash ou Moov money)
* compte bancaire
Pour ce faire, acceder au menu Virements,&#x20;
### Configuration de la méthode de remboursement
iPayMoney offre deux (02) modes de reversement facilement configurable. Les modes de reversement disponibles sont: le reversement par période et le reversement par palier.&#x20;
#### Retrait par période <a href="#reversement-par-periode" id="reversement-par-periode"></a>
Avec le reversement par période, vous pouvez choisir à quelle fréquence vous aimeriez récupérer vos avoirs. Voici les différentes options:&#x20;
* [ ] Reversement chaque 03 jours;
* [ ] Reversement hebdomadaire (une fois par semaine si le solde du compte le permet) ;
* [ ] Reversement mensuel (une fois par mois si le solde du compte le permet) ;
* [ ] Reversement annuel (une fois par an si le solde du compte le permet).
iPayMoney utilisera l'option choisie pour faire les reversements soit sur votre compte mobile money soit sur votre compte bancaire.
#### Retrait par palier <a href="#reversement-par-palier" id="reversement-par-palier"></a>
Cette option vous permet de choisir à partir de quel montant disponible sur votre compte, iPayMoney devra effectuer les reversements sur votre compte mobile money ou sur votre compte bancaire.
{% hint style="danger" %}
Le montant doit être supérieur ou égal à **50000 FCFA** et ayant fait plus de trois (03) jours sur le compte du marchand conformement aux textes de reglementation de iPayMoney.
{% endhint %}
#### Méthodes de reversement
Les reversements peuvent se faire sur compte mobile money ou compte bancaire. Les informations des comptes doivent être enregistrées au moment de la configuration du reversement.
Les frais liés au reversement sont detaillés dans le titre [Frais liés aux opérations](/ipaymoney/paiements/frais.md).
# Opération
Une opération financière est une transaction consistant en un échange d’un actif contre une somme d’argent entre deux parties cocontractantes.
Dans le cas d'utilisation de iPayMoney, une opération peut être initée par un client ou le marchand. Sur le tableau de bord on a le recapitulatif de toutes les opérations effectuées à travers son compte. Ainsi, pour une raison ou une autre, le marchand peut être amené à mettre fin à une opération en cours. Cela peut se faire à travers le menu Paiements.&#x20;
# Fonctionnalité Webhook
Lorsqu'un événement se produit sur votre compte iPayMoney vous pouvez, en utilisant les webhooks, vous informer sur leur exécution. À ce jour, vous pouvez utiliser les webhooks afin de notifier à votre système de gestion le statut d'une transaction (la transaction, est-elle un succès ou un échec).
### **Configuration des webhooks** <a href="#configuration-des-webhooks" id="configuration-des-webhooks"></a>
Il vous faudra suivre les étapes ci-après afin de procéder à la configuration de vos webhooks :&#x20;
Cliquez sur le menu "Développeurs".
![](/files/-MlUMbRb5hEilvp7xuuP)
Ensuite, cliquez sur le sous-menu "Webhooks" en dessous du sous-menu "Clés API."
![](/files/-MlUNw_ZsC5gmhbzHFOo)
Cliquez sur le bouton "Ajouter un webhook" en haut à droite.
Dans le formulaire qui apparaît, veuillez inscrire l’URL sur lequel vous désirez être notifié. Vous pouvez entrer n'importe quel URL comme destination pour les événements. Toutefois, il doit s'agir d'une page dédiée sur votre serveur, configurée pour recevoir des événements.
![](/files/-MlUPgivqzeW5cFZcVVr)
Remplissez votre "Secret Hash". C’est votre clé API secrète, elle sera utilisée afin de vérifier la provenance des informations que vous recevez. Copiez-la du sous-menu "Clés API" pour la coller dans le champ à remplir le Secret Hash.
![](/files/-MlUQHjRJd70-s12_Jqg)
{% hint style="danger" %}
**Attention !** Ne partagez surtout pas votre clé secrète.

Choisir les événements pour lesquels vous souhaitez être averti. Vous serez averti uniquement des événements spécifiés. Notez qu’il y a seulement deux (2) types d’événements : Succès et Échec.
![](/files/-MlUVKnlWRwBTWlGGsIS)
Enfin, enregistrez votre Webhook en cliquant sur "Enregistrer".
Une fois le Webhook créé, vous pouvez procéder à un test afin de vérifier que iPayMoney contacte bien votre URL.
Voilà ! Désormais, vous serez averti de toute activité sur votre compte iPayMone&#x79;**.**
### **Gérer les webhooks** <a href="#gerer-les-webhooks" id="gerer-les-webhooks"></a>
Après la configuration, il est important de comprendre l’accusé de réception d’un événement après notification d'iPayMoney. Pour ce faire, vous devez avant tout utiliser votre URL afin d'identifier le type d’événement et renvoyer un code statut HTTP 2xx. Tous les codes de réponse en dehors de cette plage, y compris les codes 3xx, indiquent à iPayMoney que vous n'avez pas reçu l'événement.
{% hint style="info" %}
En cas de non réception iPayMoney tente 5 fois de suite (dans un intervalle de 500ms incrémentable) de vous renvoyer les informations.
{% endhint %}
### **Vérification des signatures webhook** <a href="#verification-des-signatures-webhook" id="verification-des-signatures-webhook"></a>
iPayMoney signe les événements webhooks qu’il envoie à vos URL. Il est introduit dans l’en-tête de chaque requête x-iPayMoney-secret une signature. Elle est utilisée afin de vous permettre de vérifier que les événements ont été envoyés par iPayMoney et non par un tiers. Le squelette de la requête est le suivant :
```
{
  "content-length": "114",
  "accept": "application/json",
  "user-agent": "rest-client/2.1.0 (linux-gnu x86_64) ruby/2.7.2p137",
  "secret-hash": "sk_58951rhguiq859905dfn5903gh",
  "content-type": "application/json",
  "accept-encoding": "gzip;q=1.0,deflate;q=0.6,identity;q=0.3"
}
```
{% hint style="info" %}
Toutes les requête x-iPayMoney-secret utilisent le secret hash fourni par votre personne sur le tableau de bord iPayMoney.
{% endhint %}

# iPayMoney Link
iPayMoney Link est un service de iPayMoney permettant de générer des liens de paiement qu'on peut diffuser sur les réseaux sociaux. Ce lien est directement disponible sur le moteur de recherche Google. Le lien permet d'acceder à une interface conçue sur mésure permettant aux visiteurs de réaliser en toute simplicité une opération donnée (paiement de facture, don, achat de ticket, etc.)
{% hint style="info" %}
Il faut d'abord que le marchand dispose d'un compte iPayMoney actif pour utiliser iPayMoney Link.
{% endhint %}
### Fonctionnement&#x20;
Pour réussir à générer un lien de paiement iPayMoney Link, vous devrez suivre les étapes suivantes :
* [ ] Tout d'abord vous devrez renseigner le motif pour lequel le lien est en train d'être généré. Vous devez définir s'il s'agit de la vente d'un produit, d'un don, d'un règlement de facture, des acquitements de frais de participation à un événement, etc.
* [ ] Vous devrez ensuite choisir le type de lien que vous souhaitez générer : un lien unique, qui permet d'encaisser un seul et unique paiement puis expire et un lien multiple, qui comme son nom l'indique permet de réaliser de multiples paiements, donc utilisable par plusieurs personnes.&#x20;
* [ ] Dans la troisième et dernière étape, il faut renseigner les différentes informations de votre lien de paiement à savoir le nom, le montant à payer et la méthode de paiement puis cliquez sur *“Générer le lien”.*
Le lien est instantanement généré et disponible pour être partagé sur les réseaux sociaux et par mail.

# Mésures de sécurité
### Utilisation de TLS et HTTPS&#x20;
TLS désigne le processus de transmission sécurisée des données entre le client - l'application ou le navigateur utilisé par votre client - et votre serveur. Le terme SSL continue d'être utilisé de manière familière en référence à TLS et à sa fonction de protection des données transmises.
En outre, vos clients sont plus à l'aise pour partager des informations sensibles sur des pages visiblement servies en HTTPS, ce qui peut contribuer à augmenter le taux de conversion de vos clients.
Si nécessaire, vous pouvez tester votre intégration sans utiliser HTTPS, et l'activer une fois que vous êtes prêt à accepter des charges réelles. Cependant, toutes les interactions entre votre serveur et Stripe doivent utiliser TLS 1.2 (c'est-à-dire lorsque vous utilisez nos bibliothèques).
### Configuration de TLS&#x20;
Un certificat numérique - un fichier émis par une autorité de certification (CA) - est nécessaire pour utiliser TLS. Une fois installé, ce certificat garantit au client qu'il communique réellement avec le serveur auquel il s'attend, et non avec un imposteur. Vous devez obtenir un certificat numérique auprès d'un fournisseur de certificats réputé, tel que :
* Let's Encrypt&#x20;
* DigiCert
* NameCheap&#x20;
Comme TLS est une suite complexe d'outils cryptographiques, il est facile de manquer quelques détails. Nous vous recommandons d'utiliser le test de serveur SSL de Qualys SSL Labs pour vous assurer que tout est configuré de manière sécurisée.
# Sécurité mailing
Nombreux sont les internautes qui sont victimes de diverses attaques en occurence le phishing. Cette attaque se présente sous forme d'une invitation à remplir un formulaire avec ses données personnelles. Les malfaiteurs perpétrant ces genres d'attaques se débrouillent pour partager des liens qui ressemblent fortement au lien officiel. Ainsi, ils font d'énormes victimes en obtenant les informations personnelles de ces dernières.
iPayMoney enverra regulièrement les mails d'information sur votre adresse mail. Ainsi, il va falloir verifier scrupuleusement la source des mails avant de les ouvrir.
Si un mail vous para*î*t suspect, veuillez nous transmettre à l'adresse <support@i-pay.money>.
